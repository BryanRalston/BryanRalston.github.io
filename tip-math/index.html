        Feature Map
        What Tip Math does today
      
      
      Current capabilities — not a roadmap. The math stays on this device.
      
      
        
        
      • 
          Bill + optional tax
          Subtotal is required. Tax is optional. Toggle tip on subtotal or after tax.
        
        • 
        
      • 
          Tip chips
          15 / 18 / 20 / 22 / 25, plus a custom percent.
        
        • 
        
      • 
          Split 1–20
          Penny-fair seats — leftover cents go to the first seats so the table still adds up.
        
        • 
        
      • 
          Round up per person
          Each seat rounds to the next dollar. Extra becomes tip. Nobody is short a cent.
        
        • 
        
      • 
          Snapshot share
          Encodes the current check into the URL (#t= / ?t=). A friend sees the same numbers. Not live sync.

          On this device
          Last 10 checks. Store tip-math-v1. Offline cache tip-math-v1. No accounts, no analytics.
