    Feature Map — what this page does today

    Current capabilities. Not a roadmap. The meter stays on this device.

    • Leave-by hero Large leave-by time, plus minutes remaining that tick while this tab is open.
    • Duration chips 15 / 30 / 45 / 60 / 90 / 120 minutes.
    • Leave-by clock Set an exact time today, at least a minute ahead, up to 16 hours out.
    • Note Optional block, lot, or spot. Short text on this phone.
    • Amount paid Optional number. Stored locally. Never placed in the share link.
    • +15 min Extends a running meter. Hidden once the meter has ended.
    • Ended, clear, start over Close the meter, dismiss it, or go back to a fresh start. The session stays in history.
    • History Last 12 sessions: leave-by time, duration, note. Same length starts that duration again.
    • Snapshot share Packs this countdown into #m= or ?m=. A friend can open that copy. The countdown keeps running toward the shared leave-by time. It is not live sync — a later +15 min here does not move a link you already sent.
    • On this device Store leave-by-v1. Offline cache leave-by-v1. No accounts, no analytics.
