      Feature Map — what this page does today

      Current capabilities. Not a roadmap. The shelf stays on this device.

      • Log Title is required. Status is wishlist, playing, beaten, or dropped. Platform, a 0.5–5 star rating, and a one-line take are optional.
      • Edit Open a card and edit the same game. The id stays, so a card you already shared still matches this copy.
      • Remove Remove one game, or clear the shelf. Undo puts it back until the toast leaves.
      • Filters All, wishlist, playing, beaten, dropped. The filter is a view. A shelf link still packs the whole log.
      • Order Recent, or A–Z. Remembered on this device with the shelf.
      • Share card A poster for one game: title, status, stars, take. Built to be screenshotted.
      • Snapshot share Packs the whole shelf or one card into #b= or ?b=. Opening it offers that copy. It is not live sync.
      • Cap 48 games on this device. A bigger snapshot keeps what fits.
      • On this device Store beat-log-v1. Offline cache beat-log-v1. No accounts, no analytics.

      Not in this app: accounts, friends, prices, achievement sync, ads, or anything that phones home.
