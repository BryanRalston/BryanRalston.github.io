    Feature Map — what this page does today

    Current capabilities. Not a roadmap. The panics stay on this device.

    • The lock Name one questionable starter. A backup is optional. Minutes to lock are optional: a plain number like 12 shows as minutes to lock, 0 shows as Locked, and a short note like soon stays as typed. A league note is optional. This is one starter plus an optional other name. It is not a two-name start/sit booth.
    • Panic A theatrical LOCK PANIC card. A stamp, one roast line, a tag, an anxiety meter, and the names. The first roast follows the starter and backup, so the same pair keeps its line. The anxiety meter follows the stamp. It is entertainment theater, not a projection and not a model.
    • The stamp HOLD, LEAN HOLD, COIN FLIP, LEAN SWAP, or PANIC. It is seeded from the normalized starter and backup. With no backup, LEAN SWAP is filed as LEAN HOLD and PANIC is filed as COIN FLIP, because there is nobody to swap to. The roast still says no backup was named. Minutes and the note do not move the stamp, the tag, or the meter.
    • Same pair Names are NFC-lowercased. Apostrophes are dropped, so Ja'Marr and Jamarr match. Accents stay. Word order inside a name does not matter, then the words are sorted. The same starter and backup share one card, including a re-panicked roast. A later pass can save new minutes or a new note and leaves the stamp alone. The form keeps what you just typed when the pair is already on the shelf. Markup stays text.
    • Re-panic A new roast on that same stamp. It does not always open with the same phrase. The tag stays with the stamp. The anxiety meter stays. The star stays. Undo re-panic restores the previous line.
    • Star Mark a panic you want on the starred filter. Undo star takes the mark off.
    • Undo The Undo button takes back the last panic, re-panic, or star on the open card. Remove and Clear all use the toast Undo until it leaves. So does a panic that had to make room. That room Undo leaves once the new card is starred or re-panicked. The toast Undo leaves as soon as it can no longer work. A confirmation such as Link copied still shows. A form error stays on the form and does not cover a live Undo.
    • History Up to 24 panics on this phone. Filters are all and starred. Open one, remove one, or clear every panic. Opening a row does not replace what you are typing. Undo puts them back until the toast leaves. A new panic at the cap drops the oldest unstarred panic. Starred panics stay. If every panic is starred, the card refuses another.
    • Snapshot share Copy link copies the open panic into #k= in one tap. Copy shelf link packs every panic. ?k= works if the token is in the query string. The link does not carry the star. Opening it offers Keep or Not now. Keep recomputes the stamp, tag, meter, and roast from the names, so a forged line does not survive. A shelf link keeps what fits. The offer says what it adds, and how many oldest unstarred panics it drops, before you tap. If nothing fits, the offer stays up. A duplicate says Already on this phone. A keep that finds some already here says how many were new and how many were already here. An empty #k= is cleared. The address bar is cleared on purpose after a real token too. A bad token toasts. A same-tab hash change shows the offer. It is not live sync. Nothing is uploaded.
    • Load sample Ja'Marr Chase, backup A committee receiver, 12 minutes, Sunday lock. There is a card to look at without typing.
    • On this device Store lock-panic-v1. Offline cache lock-panic-v2. The page is fetched from the network when you are online. Scripts and styles carry ?v= and refresh in the background. A ?v= query is cached by pathname only. If storage is blocked, a banner says so. If a save cannot be read, including a card that fails validation, the old value is backed up and a notice shows. No accounts, no projection feed, no analytics.
