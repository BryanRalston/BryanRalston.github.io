    Feature Map

    What Clean Link does today

    A junior-crew checklist — not product chrome. Current capabilities, not a roadmap.

    • Paste → Clean → Copy Type or paste a messy URL. Clean on tap or as you paste. One-tap copy.
    • Strip trackers, keep the page utm_*, fbclid, gclid, mc_eid, igshid, si, ref, plus host extras (YouTube feature, Amazon tag, X s/t). Path, real query, and real hashes stay.
    • Unwrap then wash Facebook / Google / YouTube / LinkedIn redirect wrappers are peeled first, then the inner link is cleaned.
    • Before / after See the dirty URL, the clean URL, and chips for what got cut.
    • Copy and open Copy the clean link and open it in a new tab.
    • On this device Last 10 cleans in localStorage key clean-link-v1. Offline cache clean-link-v1. No accounts. No server.

    Cannot unwrap short links that need a network hop (t.co). Cannot see inside other people’s browsers.
